# **App Name**: BlueNova Systems

## Core Features:

- Intelligent Project Estimator: An AI-powered tool that acts as a technical assistant to help users scope their project needs and receive an instant preliminary consultation.
- Cinematic GSAP Hero Section: A high-impact landing section featuring staggered text animations and particle effects to showcase the core value proposition.
- Dynamic Service Matrix: An interactive grid layout displaying web development, mobile apps, and Salesforce solutions with micro-interaction hover states.
- Impact-Driven About Section: A storytelling component focused on the mission of building ecosystems and community empowerment, using scroll-triggered animations.
- Strategic Lead Capture: Clean, minimalist contact forms for starting projects and booking free consultations, integrated with automated email notifications.
- Tech Stack Visualizer: A sophisticated, animated gallery showcasing expertise in React, Next.js, and other modern technologies using a sleek card-based interface.
- Portfolio Spotlight: A dedicated area for showcasing landmark projects like O2Bharat using immersive full-width imagery and smooth transition effects.

## Style Guidelines:

- Primary color: Electric Cobalt (#3377FF) used for key call-to-action buttons and brand focal points to project energy and tech authority.
- Background: Midnight Navy (#0E121A), providing a deep, sophisticated canvas that makes the primary blues pop with high contrast.
- Accent color: Neon Cyan (#1AE0FF) utilized for highlights, small icons, and animated underlines to create a layered 'Blue and Blue' visual hierarchy.
- Headline font: 'Space Grotesk' (sans-serif), chosen for its tech-forward, machined feel suitable for an IT agency's bold statements.
- Body font: 'Inter' (sans-serif), ensuring maximum readability across digital platforms for dense project descriptions and mission statements.
- A set of thin-line, minimalist SVG icons featuring neon blue glows and subtle rotation animations to reflect a future-ready brand.
- Advanced GSAP orchestrations including smooth vertical scroll transitions, parallax background elements, and staggered reveal animations.
- An award-winning agency-style layout with asymmetric grid placements and generous whitespace to allow technical content to breathe.
